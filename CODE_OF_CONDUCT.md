# Code of conduct

This project adopts the spirit and the enforcement guidelines of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; argue about the code, the numbers and the design, never about the person; assume good faith; accept that a
measurement can overturn an opinion, including your own. Harassment, discrimination and personal attacks are not accepted in issues, pull requests,
discussions or any other space of the project.

Report a problem to the maintainer at the address given in [`SECURITY.md`](SECURITY.md). Maintainers may edit or remove contributions that break these rules and may
ban a participant from the project.
