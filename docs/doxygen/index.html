CoreLR plotter firmware: API reference

The firmware is built as two images from the same sources, chosen by CORELR_JOB_SOURCE. Each has its own documentation, generated as the compiler sees that image: the code that exists in only one of them appears only there.

  • serial variant: jobs streamed over the serial link (Candle, a grbl 1.1 subset)
  • sd variant: jobs read from an SD card, with the file browser
